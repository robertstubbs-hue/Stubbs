# Rob Stubbs — French Tutor (Wokingham)

Single-page marketing site for private French tuition: about, experience, qualifications, rates, interactive weekly availability, and contact.

## Stack

- [Vite](https://vite.dev/) + React (TypeScript)
- [Tailwind CSS](https://tailwindcss.com/) v4

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Contact placeholder

Update the email address in `src/App.tsx` and `src/components/AvailabilityCalendar.tsx` when going live.
